# Privacy policy pages

Generated by `scripts/generate-legal.py` from `assets/legal/content.json` and the app translations. Publisher/contact information was supplied for public display by Zerrino.

Publish `index.html`, `privacy-fr.html`, `privacy-pt.html` and `privacy-zh.html` together on a public HTTPS static host when ready. `index.html` is the English policy with language links and the medical notice. The files work without JavaScript, external fonts or sign-in and make no analytics requests.

These pages are **not published**. A public URL is still needed in App Store Connect and Play Console. After hosting, set that HTTPS URL in `assets/legal/content.json` and rebuild to add the optional online link. The complete policy is already readable offline in both apps.

See `docs/STORE-SUBMISSION.md` for the official requirements and console information.
